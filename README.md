# Overlay Trace

Float a screenshot over any app, lock it click-through, and trace its settings.
Made for Windows 11 in C#. No install needed, just run the .exe.

Version 0.1b (beta). Built with AI assistance.

## How to use
1. Open or paste a screenshot (Ctrl+V). PNG, JPG, BMP, GIF and TIFF work.
2. Set the opacity, size and position, and drag the edges to stretch it.
3. Press Alt+1 to lock it. It stays on top and clicks go straight through to the app underneath.
4. Press Alt+0 to unlock it again.

## Download
Get OverlayTrace_v0.1b.zip from the Releases page, extract it, and run OverlayTrace.exe.

Windows may show a "protected your PC" message because the app isn't code-signed yet.
Click More info, then Run anyway. The checksum for each release is in its notes.

## Features
- Opacity slider, invert colours, 30-step undo/redo
- Drag the edges to stretch, with an optional aspect-ratio lock
- Window resizes down to a narrow strip

## Build from source
Needs the .NET Framework C# compiler (csc), included with Windows.
